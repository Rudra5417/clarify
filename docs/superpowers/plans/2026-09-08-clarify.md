### Task 2: Sure/unsure rules

**Files:**
- Create: `src/clarify/confidence.py`
- Test: `tests/test_confidence.py`

**Interfaces:**
- Consumes: `Card`, `CardField` from `clarify.schema`
- Produces: `Evidence(text_layer: str | None, vision_values: dict[str, str] | None, source: Literal["file", "selection", "visible_fallback"])`; `apply_confidence(card: Card, evidence: Evidence) -> Card`

Rules (spec §5), applied field-by-field. Default `unsure`. A field is `sure` only if: value is literally in `evidence.text_layer` when text_layer is not None; if `vision_values` also has that key they must match; no two conflicting values; `source != "visible_fallback"`; a check was possible (`text_layer` or `vision_values` exists). If `text_layer` is None and `vision_values` is None, every field is `unsure` with reason `"cannot check"`. If `source == "visible_fallback"`, every field is `unsure` with reason `"visible text fallback"`.

```python
# src/clarify/confidence.py
from dataclasses import dataclass
from typing import Literal

from clarify.schema import Card, CardField

Source = Literal["file", "selection", "visible_fallback"]


@dataclass(frozen=True)
class Evidence:
    text_layer: str | None
    vision_values: dict[str, str] | None
    source: Source


def _literally_present(value: str, text: str) -> bool:
    return value.strip() != "" and value.strip() in text


def apply_confidence(card: Card, evidence: Evidence) -> Card:
    fields: list[CardField] = []
    for field in card.fields:
        status, reason = _status_for(field, evidence)
        fields.append(field.model_copy(update={"status": status, "reason": reason}))
    return card.model_copy(update={"fields": fields})


def _status_for(field: CardField, evidence: Evidence) -> tuple[str, str | None]:
    if evidence.source == "visible_fallback":
        return "unsure", "visible text fallback"
    if evidence.text_layer is None and evidence.vision_values is None:
        return "unsure", "cannot check"
    value = field.value
    in_text = evidence.text_layer is not None and _literally_present(value, evidence.text_layer)
    vision = evidence.vision_values.get(field.key) if evidence.vision_values else None
    if vision is not None and evidence.text_layer is not None and vision != value and in_text:
        return "unsure", "text and vision disagree"
    if vision is not None and value != vision and not in_text:
        return "unsure", "text and vision disagree"
    if evidence.text_layer is not None and not in_text:
        return "unsure", "not on page"
    if evidence.text_layer is None and vision is not None and vision != value:
        return "unsure", "text and vision disagree"
    if evidence.text_layer is None and vision is None:
        return "unsure", "cannot check"
    if in_text or (vision == value):
        return "sure", None
    return "unsure", "not on page"
```

Keep the disagreement / presence logic correct so the four tests pass; adjust `_status_for` until they do. Do not use model-reported percentages.
